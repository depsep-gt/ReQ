# ReQ

## More-so refined version of Experimental branch.
Welcome to the ReQ! In this repo, we are trying to create a level editor, developer SDK, and a easier-to-read codebase for the game Quake 3.

If you find any issues, please report them in the Issues tab.

## This engine uses the base code from [ioquake3](https://github.com/ioquake/ioq3)!
